# Error Analysis

## Error Type 1

Evidence-Free Conclusions

Example:

Assuming compliance based on status labels alone.

---

## Error Type 2

Process Compliance Failure

Example:

Treating incomplete PPAP evidence as approval.

---

## Error Type 3

False Generalisation

Example:

Extrapolating population quality from a limited sample.

---

## Error Type 4

Supplier Risk Underestimation

Example:

Accepting supplier statements without verification.

---

## Error Type 5

Geopolitical Blind Spots

Example:

Assuming diversification exists despite common upstream dependencies.
